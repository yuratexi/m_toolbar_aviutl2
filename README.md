# AviUtl2 プラグイン - ツールバー追加プラグイン
ツールバー追加プラグイン(m_toolbar_aviutl2.aux2)は、以下のようにAviUtl2にツールバーを追加するプラグインとなります。   
<img width="1920" height="1032" alt="image" src="https://github.com/user-attachments/assets/dee5dfbf-91a3-4ee1-a8f3-a058eef0e3d0" />
　　
要するに、Aviutlにあったaoytsk様の拡張ツールバーっぽいプラグインです。(結構仕様が違う気がしますが...)  



[ダウンロードはこちら](https://github.com/yuratexi/m_split_timeline_aviutl2/releases/latest)

詳しくは紹介動画をご覧ください。

## 動作確認
* Aviutl ExEdit2 beta35

## 導入方法
1. [Releaseページ](https://github.com/yuratexi/m_split_timeline_aviutl2/releases/latest)のAssets欄からm_split_timeline_aviutl2.zipをダウンロード
2. zipファイルを展開して出てきた"m_split_timeline_aviutl2.aux2"をaviutl2にドラッグアンドドロップ

## 仕様
紹介動画のほうで詳しく解説してます。ですがこちらにも一応ざっくり書きます。

* Aviutl2に「ツールバー」というウィンドウを追加します。  
  (表示方法:表示→ツールバー をクリック)
* ウィンドウに表示されている対応するボタンをクリックすると、対応する動作をします

* その他にも、以下のような機能を搭載しています
  * アイコンを自分専用に変更する
  * アイコンの並び順を変更する
  * ボタンの大きさを変更する(8p～64pxの範囲)
  * 不必要なボタンを削除する
  * 新たにボタンを追加する(別のプラグインの機能など...)   

## 設定方法
au2pkgをaviutl2にドラッグアンドドロップすると、"C:\ProgramData\aviutl2\Plugin"にm_toolbar_aviutl2というディレクトリ(フォルダ)が生成されます。(デフォルト設定の場合)  
その中に、以下のものが生成されています。
* iconディレクトリ(フォルダ) ← アイコンに設定する画像が格納されているフォルダ
* toolbar_buttons.ini ← アイコンの表示非表示,および並び替え,ボタンの追加をする設定ファイル

### toolbar_buttons.iniの構文
ファイルのヘッダー部に書いてある内容をひとまず引用します。  
>ツールバーボタン設定
>形式: ラベル,タイプ,パラメータ
>  タイプ: object (オブジェクト作成) / command (メニューコマンド実行)
>  パラメータ: エフェクト名 または メニュー名 (例: 元に戻す) または メニューID (10進数)
>区切り線: ---
>空行・# で始まる行は無視されます
  
**なお、ファイル内容を変更後AviUtl2を再起動しないと反映されないのでご注意を...**

objectは、タイムライン上で右クリックすると出てくる、メディアオブジェクトを追加,フィルタオブジェクトを追加の中に入っているやつです。  
commandは、メニューバー(上の方にあるファイルとか編集とか書いてあるやつ)で選択できるものです。  

ラベルは、iconフォルダの中にある表示させたいアイコンのファイル名(拡張子を除く)です。(アイコンが存在しない場合、ラベルの文字列をそのまま表示する)  
パラメーターについては、一応メニューID(wID)が指定できるようにしていますが、よっぽど特殊な事情がない限り使わないほうがいいと思います(プラグインの追加、AviUtl2自体のアップデートによってwIDが変化するため)  
これらの機能を駆使して、自分好みのツールバーを作れます。  
ちなみに、並び順についてはファイルの上の行の方から順に並ぶようになっているので、行を入れ替えることで並び順を変化させることができます。  
不必要なボタンを削除したい場合は、該当の要素が書かれている行を削除するもしくはコメントアウト(先頭に#をつける)することでボタンが削除されます。  
ちなみに、ヘッダーに書いてある構文で他の方が作成したプラグインの機能を新たにボタンとして追加するということも可能です。

ちなみに、アイコンはVisual Studio Image Libraryをもとにcopilotに選んでもらったり作成してもらったりしたものを当てています。  
もしもアイコンを自分自身で変える場合は、ラベルのファイル名でiconフォルダに画像ファイルを入れればいいです(BMP画像,24ビットビットマップ)  
うまくいかない場合は、iconフォルダ内にある「うまく表示されない場合.txt」を参照してください  
一応、以下にも同じ内容を記しておきます
>■ ツールバーに画像が表示されない場合の対処法
>
>【推奨される画像形式】
>・24ビット ビットマップ (.bmp)
>・推奨サイズ: 16×16 ピクセル (他のサイズでも自動リサイズされます)
>・toolbar_buttons.ini の button_size= でボタンサイズを変更できます (8～64)
>
>【手順1】Windows ペイントで画像を開く
>1. 画像ファイルを右クリック → [編集] (ペイントで開く)
>2. [ファイル] → [名前を付けて保存] → [BMP 画像]
>3. ファイル名の下にある [ファイルの種類] で「24ビット ビットマップ」を選択
>4. このフォルダ (icon) に保存
>
>【手順2】ファイル名を確認
>・ファイル名は toolbar_buttons.ini の「ラベル」部分と完全一致する必要があります
>  例: toolbar_buttons.ini に「画像,画像ファイル」と書かれている場合
>      → ファイル名は「画像.bmp」にする
>
>・ファイル名に使えない文字 (\, /, :, *, ?, ", <, >, |) が含まれていないか確認
>
>【手順3】AviUtl2 を再起動
>・画像を追加・変更した後は AviUtl2 を再起動してください
>
>【トラブルシューティング】
>・ログウィンドウ (表示 → ログ) で "BMP検出" や "画像を読み込みました" が
>  表示されているか確認してください
>・"LoadImageW失敗" が表示される場合は、ペイントで保存し直してください
>
>【配置場所】
>・このフォルダ (Plugin\m_toolbar_aviutl2\icon) に .bmp ファイルを配置
>・設定ファイル: Plugin\m_toolbar_aviutl2\toolbar_buttons.ini
>
