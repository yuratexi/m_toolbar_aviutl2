# AviUtl2 プラグイン - UIプリセット (`m_ui_preset_aviutl2`)

プロジェクトの**アスペクト比**（シーン解像度から算出）ごとに、いまの UI レイアウトを保存・復元する汎用プラグインです。

例: 16:9 用レイアウトと 9:16 用レイアウトを切り替えて使う。

## 動作確認想定

* AviUtl ExEdit2 beta35 以降（`RequiredVersion = 2003300`）
* シーン変更ハンドラ / `get_edit_info` が使える本体

## 導入方法

1. Windows 上で `build.bat` を実行し、`build\plugins\m_ui_preset_aviutl2.aux2` を生成する
2. `.aux2` を AviUtl2 にドラッグアンドドロップする  
   （配置先: `C:\ProgramData\aviutl2\Plugin\` など）

## 使い方

表示メニューから「UIプリセット」ウィンドウを出すか、編集メニューの「UIプリセット」から操作します。

| 操作 | 内容 |
| --- | --- |
| **現在の比率で保存** | 現在のシーン解像度を約分した比率キー（例: `16:9`）でレイアウトを保存 |
| **defaultとして保存** | どの比率にも当てはまらないときのフォールバックを保存 |
| **マッチするプリセットを適用** | 現在比率に合うプリセットを手動適用 |
| **プリセット一覧をログに表示** | 登録済みキーをログウィンドウへ出力 |
| **現在の比率のプリセットを削除** | 現在キーのプリセットを削除 |
| **自動適用の切替** | シーン変更・プロジェクト読込時の自動適用 ON/OFF |
| **設定フォルダを開く** | `Plugin\m_ui_preset_aviutl2` を開く |

設定ファイル: `C:\ProgramData\aviutl2\Plugin\m_ui_preset_aviutl2\presets.ini`

## 比率マッチング

1. シーン `width` / `height` を GCD で約分 → キー `W:H`（例: 1920x1080 → `16:9`）
2. キー完全一致があればそれを使う
3. なければアスペクト比の相対差 `\|a-b\|/max(a,b)` が `match_tolerance`（既定 0.02）以内の最近傍を使う  
   （例: 16:9 と 1920:1082 などわずかな差）
4. それでも無ければ `default` があればそれを使う

## プリセットが保存するもの / しないもの

AviUtl2 SDK にはドッキングレイアウトの読み書き API が無いため、Win32 で取得できる範囲を保存します。

### 保存する

* ホストメインウィンドウの `WINDOWPLACEMENT`（位置・サイズ・表示状態）
* 同一プロセスの**トップレベル**ウィンドウ（分離したパネル等）の配置・表示状態（タイトルで対応付け）
* ホスト直下の**タイトル付き子ウィンドウ**の相対矩形・表示状態（タイトルで対応付け）
* 保存時のシーン解像度（参考情報）

### 保存しない / 不完全になり得る

* ドッキング分割ツリー本体・タブグループ構成（公開 API なし）
* AviUtl2 本体の「表示 → レイアウト設定」が使う内部レイアウトデータ
* タイトルが空の内部コントロール
* タイトルが重複するウィンドウ（先に見つかった方のみ）

複雑なドッキング構成は、本体のレイアウト設定で名前付き保存しておき、本プラグインは「比率の切替トリガ + ウィンドウ配置の補助」として使う想定です。

## ソースからビルド

Visual Studio（C++ デスクトップ開発）と付属 CMake/Ninja が必要です。

```bat
cd m_ui_preset_aviutl2
build.bat Release
```

成果物: `m_ui_preset_aviutl2\build\plugins\m_ui_preset_aviutl2.aux2`

## リポジトリについて

新規 GitHub リポジトリ `yuratexi/m_ui_preset_aviutl2` をこの環境から作成できなかったため、当面 `m_toolbar_aviutl2` 配下の自己完結フォルダとして置いています。  
独立リポジトリにする場合は、この `m_ui_preset_aviutl2/` ディレクトリ一式をルートにコピーしてください。
