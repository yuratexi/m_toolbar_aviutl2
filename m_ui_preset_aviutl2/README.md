# AviUtl2 プラグイン - UIプリセット (`m_ui_preset_aviutl2`)

名前付き UI レイアウトをあらかじめ用意し、**ユーザーが選んでプロジェクトに紐づける**汎用プラグインです。

アスペクト比（`16:9` / `9:16` など）はプリセットの**整理用ラベル**です。比率を嗅いで自動切替する動作はしません。

## 想定ワークフロー

1. 横長用・縦長用など、好みの UI 配置をそれぞれ組む
2. 「名前を付けて保存」でプリセット化（比率ラベルは任意。例: `16:9`）
3. 使いたいプリセットを一覧から選び「適用して紐づけ」
4. プロジェクトを保存すると、選んだプリセット名がプロジェクトに記録される
5. 次回そのプロジェクトを開くと、紐づいたプリセットを適用。紐づけが無ければ**既定プリセット**を適用

## 動作確認想定

* AviUtl ExEdit2 beta35 以降（`RequiredVersion = 2003300`）
* `PROJECT_FILE` の `get/set_param_string`、プロジェクト load/save ハンドラが使える本体

## 導入方法

1. Windows 上で `build.bat` を実行し、`build\plugins\m_ui_preset_aviutl2.aux2` を生成する
2. `.aux2` を AviUtl2 にドラッグアンドドロップする

## 使い方

表示メニューから「UIプリセット」ウィンドウを出すか、編集メニュー「UIプリセット」から操作します。

| 操作 | 内容 |
| --- | --- |
| **名前を付けて保存** | 現在のレイアウトを名前付きプリセットとして保存（比率ラベル任意） |
| **適用して紐づけ** | 選択プリセットを適用し、現プロジェクトへ名前を書き込む |
| **プロジェクトに紐づけ** | 適用せず紐づけだけ更新 |
| **既定に設定** | プロジェクトに紐づけが無いときのグローバル既定 |
| **削除** | 選択プリセットを削除 |
| **フォルダ** | 設定フォルダを開く |
| 一覧をダブルクリック | 「適用して紐づけ」と同じ |

### 設定ファイル

| ファイル | 内容 |
| --- | --- |
| `Plugin\m_ui_preset_aviutl2\presets.ini` | 名前付きプリセット本体 |
| `Plugin\m_ui_preset_aviutl2\config.ini` | `default_preset=` グローバル既定名 |

### プロジェクトへの永続化

AviUtl2 SDK の **プラグイン固有プロジェクト領域** (`PROJECT_FILE::set_param_string`) にキー `ui_preset` でプリセット名を保存します。

- 適用時 / 明示紐づけ時に即座に書き込みを試行
- プロジェクト保存ハンドラでも再書き込み（確実に残す）
- プロジェクト読込ハンドラで読み出し → 紐づけがあれば適用、無ければ既定

**フォールバック:** `PROJECT_FILE` が取れない／編集ロック中で書けない場合はメモリ上の紐づけのみになり、保存ハンドラ待ちになります。サイドカーファイル方式は未使用です（SDK で足りるため）。

## プリセットが保存するもの / しないもの

### 保存する

* ホストメインウィンドウの `WINDOWPLACEMENT`
* 同一プロセスのトップレベル窓（分離パネル等）の配置・表示（タイトル対応）
* ホスト直下のタイトル付き子窓の相対矩形・表示
* 組織用 `ratio` ラベルと、保存時のシーン解像度（参考）

### 保存しない

* ドッキング分割ツリー / タブグループ（公開 API なし）
* 本体「表示 → レイアウト設定」の内部データ

## ソースからビルド

```bat
cd m_ui_preset_aviutl2
build.bat Release
```
